## portfolio/ — сайт-портфолио Оксаны (bysergeeva_design)

- `index.html` — черновой макет: первый экран, кейсы, услуги и цены, обо мне и процесс, отзывы, контакты. Каждый `<section>` — отдельный блок для переноса в Taplink/Tilda. Места, которые нужно заполнить, помечены красной пунктирной меткой. Стиль по референсу «дизайн поста-карусели»: графитовый фон, светлые слайды, крупный серифный заголовок, жёлтые выделения. Цвета и шрифты — в токенах `:root`.
- `case-nina-phone.jpg` — превью сайта Нины для кейса
