## .claude/skills/ — скилы по UX/UI-дизайну

Собраны по 18 книгам из [подборки Нетологии](https://netology.ru/blog/luchshie-knigi-po-ui-ux-dizajnu); в Claude Code подключаются автоматически по теме задачи или вызываются как `/имя-скила`.

- `ux-audit` — комплексный аудит сайта или макета по общему чек-листу
- `ux-strategy` — оффер, конкуренты, проверка идеи, воронка (Леви)
- `ux-psychology` — внимание, память, решения (Уэйншенк, Уэлен, Бриджер)
- `interface-design` — принципы интерфейса, сценарии, формы, ошибки (Норман, Купер, Бирман, Шуваев)
- `ux-writing` — кнопки, ошибки, подсказки, уведомления (Егерев)
- `emotional-design` — характер бренда, сторителлинг, привычка (Уолтер, Луптон, Эяль)
- `color-harmony` — палитра, контрасты, гармонии (Иттен)
- `typography-layout` — шрифты, отступы, сетка, правила набора (Горбунов, Королькова)
- `mobile-first` — мобильная версия, касание, формы (Вроблевски)
- `presentation-design` — слайды и визуализация (Дуарте)
- `creative-ideation` — техники генерации идей (Микалко)
