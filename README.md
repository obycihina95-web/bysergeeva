# bysergeeva

Материалы проекта «Клиенты Таплинк».

## nina/ — сайт Нины Евстафьевой (ninaevstafeva.pro, Taplink)

- [`site-status.md`](nina/site-status.md) — состояние сайта на 9 октября 2026: страницы, статусы, что осталось сделать
- `palette-variant3.md` — палитра варианта 3 («Хлопок и лесной зелёный») и настройки темы Taplink
- `variant3-phone.png` — превью варианта 3 на телефоне
- `new-tabs/texts-two-tabs.md` — тексты вкладок «Группы практики» и «Терапевтическая группа», разложенные по блокам
- `new-tabs/cowork-prompt.md` — задание для заполнения этих двух вкладок в редакторе Taplink
- `hero-photo/` — фото Нины для шапки: оригинал, вырезка, варианты фона; на главной сейчас стоит `nina-hero-photo-wall.jpg`
- `sources/` — исходные тексты Нины (.docx) для страниц «Исследование сказок» и «Киноклуб для психологов»

## portfolio/ — сайт-портфолио Оксаны (bysergeeva_design)

- `index.html` — клиентское портфолио в стиле bysergeevadesign.ru: рабочий стол, папки-кейсы с окнами, виджеты (услуги, процесс, отзывы, статус), док, 4 темы
- `case-nina-phone.jpg`, `img/` — превью для окон кейсов
- `texts.md` — тексты сайта по блокам, черновик 1
- `content.md` — факты для текстов сайта из проекта в Cowork (услуги, цены, кейсы, контакты) и открытые вопросы
